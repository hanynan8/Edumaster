# رفع اختبارات تحديد المستوى من PDF (بدل Excel)

## الفكرة
بدل ملف Excel بـ 5 شيتات، الأدمن بيكتب الاختبار في Word / Google Docs بصيغة ثابتة (سطر لكل كلمة مفتاحية)، يصدّره **PDF نصّي**، ويرفعه من:
**لوحة الأدمن ← Level Tests ← Manage tests ← Upload a new test**.

النظام بيقرا النص، يحوّله لنفس شكل الـ Excel القديم في الذاكرة، ويعدّيه على نفس الـ importer — يعني **نفس التحقق، نفس رسايل الأخطاء، ونفس شكل التيست** بالظبط زي A1/A2/B1. بعد الحفظ، رفع ملفات الأوديو بيتم من "Audio & results" بنفس النظام الحالي.

ملاحظات:
- الملف لازم يكون PDF **نصّي** (Export من Word/Docs) مش صورة ممسوحة.
- استخدم Single line spacing وبدون Header/Footer. أرقام الصفحات (سطر فيه رقم بس) بتتجاهل.
- ممكن كمان ترفع **.txt** بنفس الصيغة، أو **.xlsx** القديم (لسه شغال).
- القالب: زرار **PDF template** (فيه شرح بالإنجليزي + مثال شغّال)، أو TXT للنسخ في Word، أو Excel القديم.
- أي تيست مخصص موجود تقدر تنزّله **PDF / Excel** من كارت التيست، تعدّل فيه، وترفعه بـ "Update from file".

## الصيغة

```
TEST: b2 | LEVEL: B2 | TITLE: Prueba de nivel B2 | LANGUAGE: es | THRESHOLDS: 40,60,80
PART: Comprensión de lectura | 45
TASK: Tarea 1. Mensajes breves
INSTRUCTIONS: Lee y elige la opción correcta.
PASSAGE: نص مشترك لكل أسئلة المهمة (اختياري)
Q: نص السؤال
CONTEXT: نص خاص بالسؤال ده بس (اختياري)
a) خيار
b) خيار
c) خيار
ANSWER: b
```

| الكلمة | المعنى |
|---|---|
| `TEST:` `LEVEL:` `TITLE:` | أول سطر، مطلوبين. بينهم `\|`. `LANGUAGE:` (الافتراضي es) و`THRESHOLDS:` (الافتراضي 40,60,80) اختياريين |
| `PART:` | الجزء، وبعده `\| دقائق` اختياري |
| `TASK:` | المهمة داخل الجزء |
| `INSTRUCTIONS:` / `PASSAGE:` | تعليمات / نص مشترك للمهمة كلها |
| `Q:` | السؤال. `CONTEXT:` بعده (أو قبله) لنص خاص بالسؤال |
| `a)` … `f)` | من 2 لـ 6 خيارات بالترتيب (`a.` و`(a)` كمان مقبولين) |
| `ANSWER:` | حرف الإجابة، أو نص الخيار نفسه |
| `BANK:` | مهمة ربط: سطر لكل نص `(A) ...` `(B) ...`، وبعدها `Q:` بدون خيارات و`ANSWER: C` |
| `# ...` | تعليق بيتتجاهل |

**الفقرات:** سطر فاضي جوه `PASSAGE` / `SCRIPT` / `INSTRUCTIONS` = فقرة جديدة. الرمز `\n` جوه السطر = سطر جديد. الالتفاف العادي للسطر في الـ PDF بيتدمج في جملة واحدة. (في `SCRIPT` السطر اللي بيبدأ باسم متحدّث زي `Mujer:` بيتحسب سطر جديد.)

## أماكن الأوديو

علامة `[AUDIO]` بتغطي **الأسئلة اللي بعدها لحد العلامة اللي بعدها أو نهاية المهمة**.

| مكان العلامة | النتيجة |
|---|---|
| تحت `TASK` قبل أول سؤال (وعلامة واحدة) | أوديو للمهمة كلها (Task Audio Slot) |
| جوه سؤال، أو قبل سطر `Q:` | أوديو للسؤال ده وللي بعده (Question Audio Slot) |
| بعد `PART` وقبل أول `TASK` | أوديو لكل مهام الجزء اللي مفيهاش علامات خاصة بيها |

أشكال العلامة:
- `[AUDIO]` — رقم أوتوماتيك بالترتيب (1، 2، 3…).
- `[AUDIO 5]` — رقم يدوي ثابت. **استخدمه لما تضيف مكان جديد في تيست اتنشر وارتفعله أوديو**، عشان الأرقام ما تتزحزحش.
- `[AUDIO: اسم]` أو `[AUDIO 5: اسم]` — الاسم اللي بيظهر في لوحة الأدمن.
- `[NO AUDIO]` — بتوقف تغطية الأوديو اللي قبلها (مثلاً سؤال من غير صوت بعد سؤال بصوت).
- `SCRIPT:` بعد العلامة — نص التسجيل (للأدمن بس، مبيظهرش للطلاب).

مثال: Q1 وQ2 بتسجيل واحد، Q3 بتسجيل تاني، Q4 من غير:
```
TASK: Tarea 1
[AUDIO]
Q: ...      (Q1)
Q: ...      (Q2)
[AUDIO 5: Mensaje 2]
Q: ...      (Q3)
[NO AUDIO]
Q: ...      (Q4)
```

## الأخطاء
كل خطأ بيطلع بالعربي والإنجليزي + **رقم السطر ومقتطف منه** (من النص المستخرج من الـ PDF). لو فيه أخطاء في الصيغة نفسها (نص مش مفهوم، خيارات مش بالترتيب…) بتظهر الأول، وبعد ما تصلّحها بتظهر أخطاء التحقق (إجابة مش من الخيارات، ID محجوز…). مهمة أو جزء من غير أسئلة بيتتجاهل بتحذير.
